# パストラバーサル — 基本ケース

**日付：** 2026-11-14\
**難易度：** Apprentice\
**結果：** 完了

## 1. 脆弱性の概要

ユーザーがファイルパスを操作し、本来アクセスできないサーバー内のファイルを読み取れる脆弱性。

## 2. 根本原因

ユーザー入力から組み立てたファイルパスについて、参照先が許可されたディレクトリ内に収まるか検証していないこと。

## 3. 攻撃の仕組み

画像取得APIの `filename` パラメータに `../../../etc/passwd` を指定し、Linuxのユーザーアカウント情報を取得した。

## 4. 防御方法

- ユーザー入力を適切に検証する
- 正規化したパスが許可ディレクトリ内にあることを確認する
- ファイルIDなどの許可リスト方式を優先する
- アプリケーションのファイルアクセス権限を最小化する

## 5. 学んだこと

- `../` は親ディレクトリを参照する
- Path Traversalは画像以外のファイル操作でも発生する
- HTTP 200だけでなくレスポンス本文の確認が重要
- アプリケーションの入力検証とOSのアクセス権限制御は別の防御層である
